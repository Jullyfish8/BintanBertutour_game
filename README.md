# Otak Together — hosted gameplay prototype
Two phones join one room by code or link. Two batches of five, two 10-second sides per batch. A fans first; B watches the heat and flips. Roles swap for batch two. The final arrow position decides each side's quality; burnt overrides undercooked. Both sides must be well-done for a well-done batch.

Hosted using Sites with D1 shared room state. No culinary or historical learning content is included yet. Room codes are lightweight prototype access, not personal accounts. Refreshing resumes the role in the same browser session. Gameplay timing is synchronized to the server clock.

Local: install dependencies, generate/build, apply local D1 migration, then npm start. See Sites workflow for deployment.
